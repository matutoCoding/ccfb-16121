# 铁路救援吊复方案推演系统

纯 TypeScript + 手写 WebGL2（无 three 等引擎）的浏览器端救援起重机吊复方案推演系统，数据存 IndexedDB，离线可用。

## 运行

```bash
npm install
npm run dev       # 开发服务器
npm test          # 16 项单元/集成测试（运动学精度、受力平衡、引擎端到端）
npm run build     # 类型检查 + 生产构建到 dist/
npm run preview   # 预览生产构建
```

## 六个页面

| 页面 | 功能 |
| --- | --- |
| 车型库 | 敞车/棚车/罐车/机车；车体、转向架、车钩独立部件，自重/重心/吊点可改；罐车空/半/满载重心联动 |
| 起重机 | 底盘→转台→臂根→臂节→吊钩刚体层级；回转/变幅/起升/伸缩速度上限；性能表双线性插值；吊载率 >90% 黄、>100% 红并锁定 |
| 事故现场 | 线路平面、路堤高度、路肩宽度、邻线接触网立柱参数化生成；脱轨车位置可拖、侧滚/航向/俯仰可调（含侧翻） |
| 吊复方案 | 每台起重机站位、四条支腿独立定位与垫木层数、时间轴动作编排、挂钩/摘钩、双机抬吊；实时支反力/比压/净空/吊索检查 |
| 推演回放 | 固定步长 0.1s 逐帧快照；进度拖拽、任意帧查看全部参数、危险帧清单点击跳转、落轨对轨放大细看 |
| 方案单 | 站位图、分步动作表、最不利帧支腿反力表、关键帧截图，浏览器打印/另存 PDF 带去现场 |

## 核心数学与物理（`src/core`、`src/dynamics`）

### 运动学（`dynamics/crane.ts`）

- 严格父子坐标层级：`chassis → slew(绕Y) → boomFoot → boom(绕X变幅) → section_i(沿+z顺序伸缩) → rope → hook`，每个节点只保存局部变换，世界矩阵由父级链乘得到。
- 另有一套独立的解析手算 `analyticBoomTip`（按同一层级用三角公式直算），与矩阵链路在 4 航向 × 5 回转角 × 4 变幅角 × 3 伸缩比例共 240 组姿态下互验，**最大偏差 < 1cm（实测亚毫米级）**。
- 工作半径取吊钩相对回转中心的水平距离；吊钩 xz 与臂头严格一致、绳长 = 臂头高 − 吊钩高。

### 静力学（`dynamics/statics.ts`）

- 压力中心凸包投影法：全机合力 F = (自重 + 吊重)·g，压力中心在支腿矩形内用双线性重心坐标分配四腿反力；越界（拔腿）时投影到凸包边界，越界腿反力为 0 并报倾覆风险。
- **不变量（有测试保障）**：任意姿态、任意支腿布置下，着地腿反力之和与 F 的偏差 < 1N（1e-6 kN）。
- 地面比压 = 反力 / 垫板面积（垫木逐层扩大受力面），超过路基容许承载力标红。
- 吊索夹角解析计算、单绳拉力 T = mg/(n·cos(θ/2))、绳段与车体 OBB 干涉检测；双机抬吊按重心在两吊点连线上的杠杆法则分担。

### 仿真引擎（`dynamics/engine.ts`）

- 固定步长 0.1s，动作按各机构速度上限推进；超载锁定满 10 帧自动跳过不可达动作并告警，杜绝死循环。
- 每帧产出起重机关节、吊钩、四腿反力/比压、吊索、车体位姿、接触网净空与危险项快照。
- 接触网净空：主臂线段与立柱、导线线段做三维线段最短距离（`vec3.segmentSegmentDist`），小于 2m 报警。

## 目录结构

```
src/
  core/        mat4/vec3 数学库、插值工具（列主序，与 WebGL uniform 一致）
  dynamics/    起重机运动学、静力学、现场净空、仿真引擎
  render/      手写 WebGL2：shader、网格、轨道相机、渲染器、视口交互
  services/    IndexedDB 封装与仓储
  pages/       六个页面
  seed.ts      160t 起重机、4 个车型、4 个典型现场、示例方案种子数据
test/          运动学/受力单元测试 + 引擎端到端测试
```

## 数据持久化

IndexedDB 库 `rescue-crane-sim`，四个 object store：`carModels / cranes / scenes / plans`。种子结构变更时升 `DB_VERSION` 自动清库重种。
