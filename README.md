# 铁路救援吊复方案推演系统

面向铁路局救援列车的浏览器端吊复方案推演工具。TypeScript + 原生 WebGL2 自写渲染（无 three 等引擎），数据存 IndexedDB，离线可用。

## 启动

```bash
npm install
npm run dev      # 开发, 默认 http://localhost:5173
npm run build    # 类型检查 + 生产构建到 dist/
npm test         # Node 侧数值正确性测试 (17 项)
```

## 六个页面

| 页面 | 能力 |
| --- | --- |
| 车型库 | 敞/棚/罐/机车四类, 车体/转向架/车钩独立部件, 自重/重心/吊点可改; 罐车空/半/满载联动重心 |
| 起重机 | 刚体层级操控、性能表插值查额定、吊载率实时联锁 (90% 黄/100% 红锁车)、支腿反力与比压、1cm 自检 |
| 事故现场 | 线路平面/路堤/路肩/接触网参数生成, 脱轨车位置与侧倾角可拖拽, 起重机站位 |
| 吊复方案 | 时间轴分步编排机构动作, 吊索夹角/蹭车体校验, 双机抬吊力矩分担 |
| 推演回放 | 逐帧推演, 进度拖动, 任意帧支反力/吊载率/臂长/半径, 危险帧清单点击跳转, 落轨对轨检测 |
| 方案单 | 站位图、分步动作表、支腿反力表、关键帧参数, 可打印/另存 PDF, 截图导出 |

## 两条硬指标如何保证

**1. 吊钩位置误差 < 1cm。** `src/core/crane.ts` 里维护两条独立计算路径：
- 矩阵层级链：底盘→转台→臂根→主臂→伸缩节→臂尖→吊钩，每级只存相对父级的 TRS，世界矩阵 = 父级 × 局部；渲染直接消费这套矩阵；
- 解析手算：按臂长 L、变幅角、回转角、绳长用三角函数直接算臂尖与铅垂吊钩坐标。

`selfCheckKinematics()` 逐姿态对比两条路径，实测偏差在 **1e-6 m 量级（0.0006mm）**，远小于 1cm 红线。测试 `tests/crane.test.ts` 扫描 7 个回转角 × 6 个变幅角 × 3 组伸缩 × 3 个航向。

**2. 四条支腿反力之和 = 自重 + 吊载。** 静力学用平衡方程组（竖向力、绕 X 矩、绕 Z 矩）的最小范数解 `R = Aᵀ(AAᵀ)⁻¹b`，欠定方程组取 ||R||₂ 最小解（等沉降假定）。安全工况下合力偏差 < 0.001 kN。当合力落点超出支承四边形（真实倾覆临界），解出现负反力，系统迭代剔除离地腿并明确标注，而不是给出虚假的四点平衡——这正是 160t 支腿下沉类事故需要暴露的工况。

## 目录结构

```
src/
  core/        纯计算内核 (mat4 矩阵、几何、起重运动学/静力学、吊索、推演步进、内置数据)
  render/      原生 WebGL2 渲染器与场景装配
  data/        IndexedDB 封装 + 种子数据版本迁移
  ui/          DOM 组件、路由、六个页面
tests/         node:test 数值测试, 不依赖浏览器
```

`core/` 全部是框架无关的纯函数，可在 Node 与浏览器同构运行，所有受力与变换结论都由测试覆盖。
